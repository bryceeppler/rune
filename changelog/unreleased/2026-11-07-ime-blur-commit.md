- **An input method composition commits where it began when focus leaves.** As a browser does on blur, moving focus off a field mid-composition (a click, Tab, a focus request, the field going away, or the window deactivating) commits the text the field shows into it, and runs its `on_input_change` while it still has focus. The shell then discards the platform's composition (on Windows it now cancels it), and whatever the platform still sends for it is dropped, so it never reaches the field that took focus. A field the app removes keeps the composition until its model is shown again, when it commits there. An `App::on_ime` editor that loses the input method hears `Ime::Commit` with the text it showed, instead of only the preedit clearing.
