- **A menu or other modal that a key opened shows its first control focused.** A modal takes
  the keyboard on its first control as before, but when a key (F10, a mnemonic, a lone Alt)
  opened it since the last pointer press, primary or secondary, that focus is keyboard focus: a menu's first row shows
  its highlight and the next Return chooses it, as a menu opened with F10 does on Linux and
  Windows. A modal a click or right-click opened still waits for a key before Return chooses.
