- **A list item can sit inside a quote.** `Block::Hanging { marker, level, quote }` and `Block::Bullet { level, quote }` with `quote` set draw the quote's bar, one bar with the `Block::Quote` lines around them, and start their levels from the quote's indent, so a bullet, numbered or checklist item written inside a Markdown quote indents by level within the quote and wraps under its text. `Block::Bullet(level)` is now `Block::Bullet { level, quote }`, and `Block::quoted` says whether a paragraph draws the bar. Code that builds a `Block::Hanging` or a `Block::Bullet` passes `quote`.
