- **Windows: a close message to the app's hidden event window asks the app to quit.** `taskkill` without `/F` sends `WM_CLOSE` to every top-level window, and `Process.CloseMainWindow()` sends it to winit's hidden event window while the app's windows are minimized. That message now asks every window's `App::on_close_request`, as `Tx::request_quit` does. Before, Windows destroyed the event window, which carries every wake, so the app could never quit again and only a forced kill ended it.
