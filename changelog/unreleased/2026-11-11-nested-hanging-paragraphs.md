- **A `Block::Hanging` paragraph nests like a list item.** `Block::Hanging { marker, level }` carries its list nesting `level` `0..=MAX_LIST_LEVEL`, and each level starts the paragraph one list step further in from the side it reads from, the step a nested `Block::Bullet` takes, so a nested numbered or checklist item written as Markdown indents under its parent in left-to-right and right-to-left text. Level 0 keeps the margin, and wrapped lines still start under the text after the marker. Code that builds a `Block::Hanging` passes a `level`.
