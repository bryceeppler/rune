- **Windows: text typed as Unicode input reaches the focused field.** `SendInput` with `KEYEVENTF_UNICODE`, which password managers' auto-type, AutoHotkey and the on-screen keyboard use, sends each UTF-16 unit as a `VK_PACKET` key. The event loop now takes those keys before winit and hands their text to the window as typed text, in order with ordinary keys and with an emoji's two halves joined. Before, winit reported a character with an unidentified key, which Rune ignored, and dropped each half of a surrogate pair, so nothing was typed.
