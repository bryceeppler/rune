- **Windows: text typed as Unicode input reaches the focused field.** `SendInput` with `KEYEVENTF_UNICODE`, which password managers' auto-type, AutoHotkey and the on-screen keyboard use, sends each UTF-16 unit as a `VK_PACKET` key. The event loop now takes those keys before winit and hands their text to the window they were typed into as typed text, in order with ordinary keys, with an emoji's two halves joined and a packet's repeat count kept. Half a pair with no partner types U+FFFD in its own window before the next key, click, input method message, packet for another window, focus loss or close, and text the hook decoded reaches the window before it is asked to quit or handles anything else. A quit or close ends a waiting half before the save it asks for, and a closed window leaves no half behind for a later window with the same handle. Before, winit reported a character with an unidentified key, which Rune ignored, and dropped each half of a surrogate pair, so nothing was typed.
