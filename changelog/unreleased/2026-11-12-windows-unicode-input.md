- **Windows: text typed as Unicode input reaches the focused field.** `SendInput` with `KEYEVENTF_UNICODE`, which password managers' auto-type, AutoHotkey and the on-screen keyboard use, sends each UTF-16 unit as a `VK_PACKET` key. The event loop now takes those keys before winit and types each one into its window as it is handled, in order with ordinary keys and with a packet's repeat count kept. A high surrogate types its emoji with the low surrogate queued right behind it, as one `SendInput` call puts them; a half with no partner there types U+FFFD at once, and nothing waits across messages. Before, winit reported a character with an unidentified key, which Rune ignored, and dropped each half of a surrogate pair, so nothing was typed.
