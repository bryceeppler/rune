- **Apps decide when they close, and reopen where they were.** `App::on_close_request` asks before a window closes or the app quits and takes its answer now or later, from any thread, once a save ends: macOS Quit, ⌘Q, the Dock and logout wait through AppKit's reply-later termination, and the new `Tx::request_quit` asks every window on every platform. Closing the last main window asks the other windows as a quit instead of closing them unasked. A request waits for the window's queued input, and input that arrives while the app holds it makes a proceed ask again. Windows' session query asks every window and waits while one saves; a Windows session end and `SIGTERM` now run `on_close`, after the window's queued input, before the process ends instead of killing it. `App::on_geometry`, `WindowHandle::geometry` and `App::restore_geometry` save and restore a window's frame, state and display, moved onto a display present at launch at that display's scale. `Shell` gains `RequestQuit`, so an exhaustive `match` on it needs an arm.
